KMS激活说明 ​

1、准备工作 ​

tex
# Windows server 必须安装2024 年 2 月 13 日 - KB5034765 或更高版本的累积更新
https://www.catalog.update.microsoft.com/Search.aspx?q=KB5034765

Microsoft Update Catalog

2、创建 ​

powershell
# powershell管理员权限
Install-WindowsFeature -Name VolumeActivation -IncludeManagementTools

Set-NetFirewallRule -Name SPPSVC-In-TCP -Profile Domain,Private -Enabled True

vmw.exe

# 在“本片简介”屏幕上，选择“下一步”。 选择“密钥管理服务 (KMS)”作为激活类型，然后输入 以配置要配置的本地服务器或服务器的主机名。

# 选择“安装 KMS 主机密钥”，输入组织的产品密钥，然后选择“提交” 。

# 安装产品密钥后，需要激活产品。 单击“下一步” 。

# 从下拉菜单中选择要激活的产品，然后选择是在线激活还是电话激活。 在本示例中，选择“在线激活”，然后选择“提交”。

# 激活成功后，将显示 KMS 主机配置。 如果这是你需要的配置，可以选择“关闭”退出向导。 DNS 记录将创建，可以开始激活 KMS 客户端。 如果需要手动创建 DNS 记录，请参阅(3、KMS服务器说明支持)。如果要更改配置设置，请选择“下一步”。(可选：根据要求更改配置值，然后选择"提交")

3、KMS服务器说明支持 ​

如何在 Windows Server 中创建密钥管理服务 (KMS) 激活主机 | Microsoft Learn

4、kms激活代码 ​

powershell
# win+R    -->    cmd

# 检查激活状态
slmgr /dli

# 卸载原来电脑安装的密钥
slmgr /upk

# 安装新的对应密钥
slmgr /ipk <product key>

# 设置kms服务器
slmgr /skms <kms server ip>

# 激活
slmgr /ato

# 查询kms激活时间
slmgr /xpr
